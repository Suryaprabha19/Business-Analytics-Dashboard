# 📊 Business Analytics Dashboard (Excel)

This is an interactive **Business Analytics Dashboard** created in **Microsoft Excel**. It provides insights into participants' investment behaviors, saving objectives, information sources, and demographic distribution. The dashboard uses slicers, charts, and pivot tables to provide a user-friendly visual analysis experience.

---

## 📌 Features

- **Gender Distribution**
  - Pie chart showing the percentage of male and female participants.

- **Total Members**
  - Displays total participant count (e.g., `40` members).

- **Saving Objectives**
  - Donut chart showing responses to the question "Do you have a saving objective?"

- **Investment Duration**
  - Bar chart representing how long participants prefer to invest (e.g., 1–3 years, 3–5 years, etc.).

- **Investment Expectations**
  - Radar chart analyzing participant expectations from their investments.

- **Information Source Frequency**
  - Bar chart showing how participants access financial information (e.g., via Internet, Consultants, TV, Magazines).

- **Slicers for Filtering**
  - Gender
  - Saving Purpose (Returns, Savings for Future, Wealth Creation)
  - Saving Areas (Education, Health Care, Retirement Plan)
  - Source of Information (e.g., Internet, Consultants)

---

## 🛠️ How to Use

1. Open the Excel file containing the dashboard.
2. Use the slicers (left and right panels) to filter data by:
   - Gender
   - Purpose
   - Saving Area
   - Source
3. Watch the charts dynamically update to reflect your filters.
